# CameCallHero

Practice hunting game calls like a rhythm game. Hear real animal calls, record
yours, get scored against the real thing. Starting with the wild turkey: yelp,
cut, purr, gobble, kee kee run.

Status: under construction — see [docs/STATUS.md](docs/STATUS.md) and the plan in
[docs/PLAN.md](docs/PLAN.md). Agents working here: read [AGENTS.md](AGENTS.md).

Live site (Android Chrome): https://raineslc.github.io/CameCallHero/

Audio never leaves your phone.
